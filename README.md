# 농장 디펜스 3 — 고양이 수비대

농장 디펜스2의 웨이브·열매 포인트·정비 강화·탄환·고양이 수비대 설정을 격자형 아케이드 전장으로 옮긴 독립 웹게임입니다. 첨부 스크린샷의 벽돌, 강철 블록, 기지 수비 배치에서 영감을 얻었고, 게임 화면과 스프라이트는 새로 구성했습니다.

## 플레이

`index.html`을 브라우저에서 열면 바로 시작할 수 있습니다. 설치, 계정, 서버 연결은 필요하지 않습니다. 화면 크기에 맞춰 조정되며 휴대전화에서는 방향 패드와 발사 버튼을 사용할 수 있습니다.

- 이동: `WASD` 또는 방향키
- 발사: `Space`를 누르고 있기
- 탄환 변경: `1` BB탄 · `2` 강철탄 · `3` 돌멩이
- 바위 강타: 정비 시간에 해금하면 적이 가까이 접근할 때 자동 발동
- 일시 정지: `Esc`
- 마우스: 전장 안에서 누른 채 조준하고 발사

## 들어 있는 기능

- 단계별 작전 레벨과 경험치 레벨업
- 효린이는 레벨이 넘어가도 자동 회복되지 않으며, 매 레벨 무작위로 놓이는 종이곽 초코우유를 먹으면 체력 35 회복 (농장 수리와 체력 강화는 효린이의 현재 체력을 회복하지 않음)
- 효린이 체력이 줄어들면 성인 → 청소년 → 어린이 → 아기 모습으로 변화
- 빨간 헛간과 사일로, 경작 이랑, 딸기밭·사과밭·포도밭·옥수수밭을 구분한 농장 배경
- 두더지, 토끼, 까마귀, 멧돼지, 5레벨마다 등장하는 왕멧돼지
- 나무 울타리를 새총으로 부수고 강철 블록과 물길을 피해 헛간으로 향하는 침입자를 저지
- 정비 상점에서 농장 본진과 작물밭의 현재 체력, 수리 물자의 회복량을 확인
- 효린이의 새총은 조준 방향에 맞춰 몸 앞에서 방향을 바꾸며 탄환도 새총 끝에서 발사
- 레벨 전환 후 새 벽이 효린이나 고양이 자리를 막으면, 직전 이동 경로의 반대편(들어온 쪽)으로 자동 이동해 끼임 방지
- 열매 포인트로 새총 위력·연사·이동·방어·체력·울타리 강화, 탄환 보충, 농장 수리
- 누니(40)는 본진을 지키고, 양이(60)는 최대 430 거리의 적을 공격하며, 마루(75)는 고양이 체력을 회복
- 공격하는 고양이는 적을 향해 젤리 발바닥을 날리고, 적중하면 세 줄 할퀴기 효과와 함께 피해를 줌
- 적에게 맞으면 고양이 체력이 줄고, 작전 화면과 수비대 목록에서 체력을 확인할 수 있음
- 레벨 정비 화면, 최고 점수, 브라우저 자동 저장
- 효과음 켜기/끄기와 모바일 터치 조작

자동 저장과 기록은 `farm-defense-3.*` 키를 사용합니다. 농장 디펜스2의 저장 데이터를 읽거나 덮어쓰지 않습니다. 저장은 현재 브라우저의 LocalStorage에만 남습니다.

## 파일

- `index.html`: 실행 페이지
- `style.css`: 화면과 모바일 레이아웃
- `game.js`: 게임 진행과 저장
- `assets/`: 이 독립 실행 폴더에서 사용하는 효린이·침입자·고양이 그림
